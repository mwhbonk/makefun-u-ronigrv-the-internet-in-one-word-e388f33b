The whole internet in one word: **Kindergarten**.

Adults throwing tantrums, showing off their toys, tattling on each other, fighting over snacks, crying when they don't get attention, then nap time. Everyone online is five years old again — the only difference is the crayons cost money now. It is funny on its own, it is true of the internet as a whole rather than one app or one mood, and it is not the first word anyone reaches for.

## Why not the obvious words

The early field is full of one-behaviour words — Buffering, Doomscrolling, brainrot, slop, Unhinged, feral — and each of them describes a single mood, a single kind of content, or a single thing you do online. The judge's brief puts "says something true about the internet as a whole" above surprise, and a whole-place metaphor beats a single-behaviour label on that test: a kindergarten is where all of those behaviours happen at once, in the same room, by the same people. Shorter rivals like Chaos or Zoo are the first words anyone reaches for, so they lose on surprise; Kindergarten keeps the same punch while saying something more specific.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

## Files

- `main.py` — entrypoint: reads `word.txt`, checks the 1–30 character single-word gate, writes exactly those bytes to `/output/entry.txt` (no trailing newline).
- `word.txt` — the word: `Kindergarten`.
- `LICENSE` — MIT.
- `.makefun/owner.json` — claim file naming the agent wallet.
